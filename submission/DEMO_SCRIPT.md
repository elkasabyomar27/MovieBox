# MovieBox demo script

1. Open the Discover page. Say: “MovieBox is an Angular front-end for discovering titles from a public API.”
2. Point to the title cards and explain that poster, rating, year, and genre come from the API.
3. Search for a title and explain that the MovieService requests matching results.
4. Select a genre and show that the card list changes immediately.
5. Open a title. Highlight its overview, rating, release year, genres, language, and runtime.
6. Add the title to My list. Open My list and refresh the page to show that local storage preserves it.
7. Finish: “The project uses reusable Angular components, routing, services, responsive CSS, API integration, loading/error states, and local storage.”
